# EMA Prompting Schedule & Item Bank

## Prompting Schedule
- **Duration:** 14 consecutive days
- **Frequency:** 5 prompts per day within 2-hour windows between 09:00 and 21:00.

## Core Items (0-100 Visual Analog Scale)
1. `reappraisal_raw`: "Since the last prompt, how much did you try to change the way you were thinking about a stressful situation?"
2. `avoidance_raw`: "Since the last prompt, how much did you put off or avoid an important task?"
3. `neg_affect`: "Right now, how distressed or anxious do you feel?"
